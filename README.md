# 运行与部署 AI Studio 应用

本项目包含本地运行所需的全部内容。

在 AI Studio 中查看应用：https://ai.studio/apps/925c7405-b6f8-4ac7-b280-382a721c44f2

## 本地运行

**前置条件：** Node.js

1. 安装依赖：
   `npm install`
2. 在 [.env.local](.env.local) 中设置 `GEMINI_API_KEY`
3. 运行应用：
   `npm run dev`
